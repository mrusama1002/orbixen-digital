Overview

One platform for every
purchase order.

Small-to-medium businesses tracking purchase orders through Excel sheets or manual registers lose accuracy, visibility, and time. This system centralizes vendor relationships, order history, tax calculations, and financial reporting into a single auditable platform — so procurement teams can create, send, and track POs without switching tools or chasing paper trails.

Key Features

What the system does.

🏢
Vendor Management
Add, edit, and manage complete supplier and vendor records — contact info, history, and order totals all in one place.
📋
Purchase Order Creation
Create orders with multiple line items, quantities, unit prices, and automatic subtotal calculations per vendor.
📷
Barcode Scanning
Use a barcode scanner to quickly add products to an order at the warehouse or receiving counter — no manual lookup needed.
🧮
Tax & Discount Calculation
Automatic per-order calculation of taxes and discounts, keeping totals accurate without manual formulas.
📄
PDF & Email Export
Generate professional PO documents as PDFs and send them directly to vendors by email — no third-party tools required.
📊
Dashboard & Reporting
Real-time overview of order counts, total amounts, pending POs, and key business metrics at a glance.
🔐
Multi-User Access
Role-based login for admins and staff, keeping sensitive financial settings and full order history restricted to the right people.
⚙️
Dynamic Settings Panel
Configure company name, logo, currency, and timezone directly from the admin panel — no code changes required.
🧙
Guided Web Installer
Self-service setup wizard handles database connection and initial config on first run — no command-line deployment needed.
Modules

Everything in one place.

Four tightly scoped modules — each built to eliminate a specific manual step, not just digitise it.

Module What it does
Purchase Orders Module // 01 Vendor records, itemized orders with tax and discount rules applied automatically, one-click PDF and Excel export, and an email to the vendor the moment an order is placed.
Sales Orders Module // 02 Every line records both cost and sale price, so profit is a by-product of entering the sale — not a separate calculation. New products can be typed straight into the order and are created on save. Customer-facing invoices show price and total only.
Dashboard Module // 03 Month-by-month purchase and sales/profit charts, with date-range-filterable totals for spend, order count, revenue, and margin — all on one screen.
Access & Settings Module // 04 Role-based access across Super Admin, Admin, and Sub Admin, tenant suspension, and a settings layer that can be backed by the database, a JSON file, or Redis depending on deployment.
